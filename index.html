Explain It

1. In your own words, how does your app change a sound wave into binary? Name the three steps.
The app samples the wave’s height at equal time steps, rounds each height to the nearest level, and then writes each level in binary[cite: 2].

2. Run Test A again with 2 bits, then 6 bits. Which gives more detail about the wave, and why?
6 bits gives more detail because it has 64 levels instead of 4, allowing the binary values to follow the wave’s height much more closely, though it uses more bits[cite: 2].

3. Which test has the longest wavelength? How is wavelength connected to frequency?
Test B (200 Hz) has the longest wavelength. Higher frequencies result in shorter wavelengths[cite: 2].

4. What was the hardest stage to build, and how did you fix it?
Handling correct level rounding and binary padding for leading zeros was challenging, which was resolved by implementing precise mathematical rounding and string padding functions.
